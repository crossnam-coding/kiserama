«Glow Connection 따라 추기» 개인정보 안내

시행일: 2026-11-02 (11-05 사용 통계 항목 추가) · 운영: 주식회사 기세등등(KISERAMA Inc.) · 이 안내는 kiserama.com 개인정보처리방침에 더해 «따라 추기»에만 해당하는 내용을 적은 것입니다.

1. 카메라 영상

동작을 보기 위해 앞카메라를 씁니다. 카메라 영상은 이 폰의 브라우저 안에서만 분석하고 재생합니다. 어떤 서버로도 보내지 않고 저장하지도 않습니다. 분석 프로그램도 이 사이트에서 함께 받아 폰에서 돌립니다.

묶음(1~3·4~6·7~8)과 전체를 원래 속도로 출 때는 통과 후 다시 보여 주려고 폰 메모리에 잠깐 녹화합니다. 통과하면 다시 보여 준 뒤 지우고, 통과하지 못하면 바로 지웁니다. 후렴 전체를 마치면 «내 영상 저장·공유»를 누를 수 있습니다. 이 버튼을 직접 누를 때만 영상이 사진첩이나 다른 앱으로 넘어갑니다.

2. 이 폰에 남는 것

  • 진행 기록(어디까지 익혔는지): glink_done
  • 처음 들어온 경로 코드(예: instagram, direct): glink_src
  • 카메라 설정 번호(이 폰에서 잘 열린 카메라 방식 · 숫자 하나 · 영상 아님): glink_cam

세 기록 모두 이 폰의 브라우저 저장소에만 있습니다. 앱의 «처음부터» 버튼은 진행 기록(glink_done)만 지웁니다. Safari 설정 → 방문 기록 및 웹 사이트 데이터 지우기를 하면 셋 다 지워집니다.

3. 서버에 남는 것 (접속 기록)

이 사이트는 GitHub Pages(GitHub, Inc. · 미국)에서 제공됩니다. 사이트를 열면 일반 웹사이트처럼 GitHub에 IP 주소·브라우저 종류·시각 같은 접속 기록이 남을 수 있습니다. 회사는 이 기록을 따로 받거나 보관하지 않으며, «따라 추기»는 이름·연락처·영상·점수를 어디에도 보내지 않습니다.

사용 통계(켜져 있을 때): 몇 명이 써 보는지 세려고 GoatCounter(통계 서비스 · 서버 핀란드·독일)에 «열기·가이드·시작·자리 잡기·스텝 통과·막힘·멈춤·완주·저장·신청 버튼·안무 먼저 보기·30초 챌린지» 같은 단계 이름, 챌린지 점수(10점 단위 구간으로만), 어느 앱 안 브라우저로 열었는지(인스타그램·카카오톡 같은 종류만), 몇 번째 방문인지, 머문 시간·연습한 시간(1~3분 같은 구간으로만), 카메라를 못 연 이유(예: 허용 안 함)와 들어온 경로 코드를 보냅니다. GoatCounter는 쿠키를 쓰지 않고, IP 주소나 전체 브라우저 정보를 저장하지 않으며 묶음 통계로만 남깁니다(공식 안내 기준).

4. 보관과 파기

폰에 남는 기록은 Safari의 웹 사이트 데이터 지우기로 바로 지워집니다(진행 기록은 «처음부터» 버튼으로도). GitHub의 접속 기록은 GitHub의 정책에 따릅니다.

5. 처리 위탁·국외 이전

제3자에게 제공하지 않습니다. 사이트 호스팅은 GitHub, Inc.(미국), 사용 통계는 GoatCounter(핀란드·독일 서버)를 씁니다. 호스팅은 접속할 때 네트워크로 IP 주소·접속 기록이 전달될 수 있습니다(보유 기간은 GitHub 정책). 글꼴·분석 프로그램은 외부 서비스가 아닌 이 사이트에서 받습니다. 국외 이전을 원하지 않으면 사이트 이용을 멈추시면 됩니다.

6. 안전하게 지키는 방법

사이트는 암호화 연결(HTTPS)로만 엽니다. 카메라 영상을 서버로 보내지 않는 구조로 만들었고, 회원 데이터베이스를 두지 않습니다.

7. 수업 신청

«수업 신청하러 가기»가 보일 때는 별도의 구글 신청서로 이어집니다. 신청서에서 받는 정보는 신청서에 적힌 안내를 따릅니다. 신청서의 «링크 코드» 칸에는 예습을 마치고 신청하면 yeseup_들어온경로, 첫 화면 «바로 신청하기»로 가면 baro_들어온경로가 자동으로 채워집니다. 어느 길로 신청했는지만 세는 용도입니다.

8. 자동으로 매기는 점수

동작 점수는 폰 안에서 자동으로 계산합니다. 다음 스텝을 여는 데에만 씁니다. 사람이 점수를 보거나 점수로 다른 결정을 하지 않습니다.
